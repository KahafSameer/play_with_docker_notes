Docker Concepts

Containers

Lightweight, standalone packages that include everything needed to run an application.

Images

Read-only templates used to create containers. Built from Dockerfiles.

Dockerfiles

Scripts containing instructions to build a Docker image.

Registries

Places to store and distribute Docker images, like Docker Hub.

Volumes

Mechanisms for persisting data generated by and used by Docker containers.

Networks

Allow containers to communicate with each other and with the outside world.

Important Notes

  • Sessions expire after 4 hours of inactivity.
  • Limited resources: 1 CPU, 512MB RAM, 10GB storage.
  • Perfect for learning, not for production use.
  • All data is ephemeral - disappears when session ends.
  • Access via browser, no local Docker installation needed.

How to Use Play with Docker

  1. Go to labs.play-with-docker.com
  2. Sign up or log in with Docker Hub account.
  3. Click "Start" to begin a new session.
  4. Choose an instance (Linux node).
  5. Use the terminal to run Docker commands.
  6. Try commands like: docker run hello-world
  7. Explore Docker Compose, Swarm, etc.

Sample Commands

docker run -d -p 80:80 nginx
docker build -t myapp .
docker-compose up
